# 一键配套部署

sing-box 节点安装成功后会询问是否执行自动配套配置；已有节点进入 **d → 14**。
一次输入 y 后自动检查并安装 UFW/qrencode、启用 BBR + FQ、放行 SSH 和实际节点端口，
再启用 UFW。包含 IPv4 HY2 时自动启用 20000–30000/UDP 跳跃；已有跳跃范围保留。
这是节点安装后的配套自动化；并不代替选择节点参数和证书的安装流程。

- SSH 端口取自实际监听与当前 SSH 会话，不猜测为 22。无法确认时不自动启用防火墙。
- 新启用 UFW 前检查 nft/iptables 规则和其它公开监听服务。已有未知规则、Docker、Fail2ban
  或其它防火墙状态需要通过 d → 2 手工核对；不自动清空、覆盖或猜测兼容性。
- UFW 已启用时保留默认策略，只补充 SSH、节点、账号、订阅、证书验证及既有跳跃放行。
- 云安全组需要在服务商处另外配置；脚本只能管理本 VPS 的系统防火墙。
- BBR 只作用于 TCP。内核不支持、配置路径已有其它内容或设置失败时明确报告；
  自动设置失败会尝试恢复之前的拥塞控制和默认队列参数，不报告为已开启。
- HY2 默认跳跃范围必须不与监听端口、其它 UDP 服务和受限账号端口冲突。
  发生冲突请进入 d → 5 选其它范围。客户端 JSON/YAML 会更新；小火箭需自行核对客户端设置。
- 当前跳跃是 IPv4 实现，IPv6 节点以及 IPv6 监听、域名连接地址族未确认的节点会跳过，不把 IPv4 规则当作 IPv6 已生效。
- 二维码工具已安装则不重复安装；不会自动公开二维码、节点凭据或在线订阅。
- 四项分别报告通过、未完成或跳过。已完成的步骤保留，不因其它步骤失败而删除已安装节点。
  配套部署可以重试；已有 HY2 跳跃必须仍是本脚本管理且服务正常，否则提示检查。
