# 一键配套部署

节点安装 **a → 1 / 2 / 3 / 4** 使用自动向导：先选协议，填写节点名称，再分别选择
是否开启 BBR、是否安装并开启 UFW、是否安装小火箭二维码工具。汇总确认后，
自动完成节点安装和所选配套步骤，不再重复追问参数。输入 n 的项目跳过，不关闭或卸载已有设置。

| 自动安装默认参数 | 值 |
|---|---|
| TCP / UDP 端口 | 所选协议均为 443 |
| 公网连接地址 | 1–3 自动识别；4 使用首个通过检测的本机原生公网 IPv6 |
| Reality 握手网站 | addons.mozilla.org；安装前检测 |
| HY2 证书 | 自动自签名，客户端必须安全配置信任 |
| IPv4 HY2 跳跃 | 自动配置 20000–30000/UDP；已开启则保留现有范围 |

**a → 4** 直接安装 IPv6 Reality + Vision，使用 TCP 443；客户端必须支持 IPv6。
IPv6 HY2 / 双协议及手动 IPv6 参数入口为 **a → 7 → 10**。

**a → 9 自定义安装** 保留手动设置协议、端口、连接地址、地址族、证书和握手网站的通道；
安装后 **a → 6** 修改节点参数，**b → 8** 修改端口，BBR / UFW / 二维码分别在
**d → 4 / d → 2 / b → 4** 管理。已有节点也可进入 **d → 14** 一次确认补配全部项目。
手动安装结束仍可选择配套配置，或跳过后单独管理。

BBR 使用系统现有内核的算法并检查实际启用状态，不安装、更换系统内核，不能仅凭
算法名称 bbr 认定为 BBR v3。BBR 只影响 TCP；不直接改变 HY2 的 UDP 拥塞控制。
若不选择 UFW，HY2 仍会尝试配置跳跃，系统与云防火墙放行需自行确认。

- SSH 端口取自实际监听与当前 SSH 会话，不猜测为 22。无法确认时不自动启用防火墙。
- 新启用 UFW 前检查 nft/iptables 规则和其它公开监听服务。已有未知规则、Docker、Fail2ban
  或其它防火墙状态需要通过 d → 2 手工核对；不自动清空、覆盖或猜测兼容性。
- UFW 已启用时保留默认策略，只补充 SSH、节点、账号、订阅、证书验证及既有跳跃放行。
- 云安全组需要在服务商处另外配置；脚本只能管理本 VPS 的系统防火墙。
- BBR 只作用于 TCP。内核不支持、配置路径已有其它内容或设置失败时明确报告；
  自动设置失败会尝试恢复之前的拥塞控制和默认队列参数，不报告为已开启。
- HY2 默认跳跃范围必须不与监听端口、其它 UDP 服务和受限账号端口冲突。
  发生冲突请进入 d → 5 选其它范围。客户端 JSON/YAML 会更新；小火箭需自行核对客户端设置。
- 当前跳跃是 IPv4 实现，IPv6 节点以及 IPv6 监听、域名连接地址族未确认的节点会跳过，不把 IPv4 规则当作 IPv6 已生效。
- 二维码工具已安装则不重复安装；不会自动公开二维码、节点凭据或在线订阅。
- 四项分别报告通过、未完成或跳过。已完成的步骤保留，不因其它步骤失败而删除已安装节点。
  配套部署可以重试；已有 HY2 跳跃必须仍是本脚本管理且服务正常，否则提示检查。
