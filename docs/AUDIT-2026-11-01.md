- 修复 UFW 默认策略或启用失败仍继续执行、菜单吞掉防火墙/服务/vnStat 错误的问题。

## 检查方法与范围

- Bash 语法与 ShellCheck；Python 编译检查；生成文件一致性。
- 完整隔离回归覆盖安装、配置、真实核心代理、更新、回退、端口、IPv6、WARP、订阅及卸载。使用临时配置与模拟 systemd，不操作生产 VPS。
- 失败路径新增回归：必须把失败返回到菜单调用者；依赖失败时不继续执行后续步骤。
- 发布前由项目现有 Linux CI 再次验证，并核对公开发布附件及安装入口。

## 语法和性能判断

Bash 继续使用数组、安全引用、`[[ ]]`、明确的退出码和模块化函数；Python 使用当前标准库。保留受支持 Ubuntu/Debian 的 Python 版本兼容，不为表面上“更新”而引入无法运行的语法。

启动概览已采用有时限的查询，Xray 复用短期缓存；保持菜单渲染不安装软件、不自动检查远端版本。当前没有证据支持仅更换语法能提高网络速度。后续优先按实测拆分热点、减少重复外部进程，避免无依据地添加并发或缓存。

测试通过不代表所有 VPS、服务商防火墙和客户端组合都无 bug，也不能证明公网 TCP/UDP 可达。
