# 2026-10-29：菜单、下载地址与失败处理检查（v2.8.13）

基线 v2.8.12。检查安装/重装、核心与脚本更新、配置编辑、备份恢复、防火墙、WARP、中转、节点导出和菜单导航；未连接或改动生产 VPS。

| 已确认问题 | 处理 |
| --- | --- |
| 启动器与安装器从可变 main 分支拉取下一阶段，安装过程可能跨版本；重装没有防降级 | 同一版本的 bootstrap → install → manager 固定到 GitHub Release；校验 SHA256、唯一版本字段及入口/载荷版本一致性；拒绝覆盖更高或无法识别的已安装版本 |
| HTTP 成功但安装器为空时会静默执行完毕，未统一检查错误页面/语法 | 执行前检查非空、Bash 文件头和语法；失败清理临时文件并保留旧脚本 |
| SSH 放行规则失败分支返回成功 | 返回失败，停止防火墙启用；隔离测试确认不执行默认策略或 enable |
| 多项子菜单挤在一行，部分帮助仍写旧数字主菜单 | 每项独立一行；分类菜单显示标题，用户管理按功能分组；提示改为现有字母路径，原按键及逐层返回不变 |
| 一部分核心/脚本下载未显式限制连接等待或 HTTPS 跳转 | 统一 HTTPS-only、禁用隐式 curl 配置并加入 10 秒连接超时；保留下载总时限与摘要验证 |

菜单没有新增网络请求、常驻服务或每次绘制的格式转换进程，保留 v2.8.12 的批量查询、超时和无锁账户摘要。节点认证与转发配置不变；没有增加备用 SSH 功能。

验证覆盖：生成文件一致性、Bash 语法、ShellCheck、内嵌 Python 编译、自检、安装器空文件/错误页/损坏摘要/错误版本/防降级、失败回滚、连续菜单输入、真实本地 Reality/HY2/中转/订阅通信及原有完整回归。Linux 发布检查覆盖 Ubuntu 24.04、Debian 11/12/13；未在本机运行真实系统包安装或修改防火墙。
