## Ubuntu/Debian VPS 一键安装

需要 root、Ubuntu/Debian 和 systemd。以 root 账号登录 VPS，在 Bash 终端复制运行下面这一条命令。缺少 `curl` 时会自动安装 `curl` 和 CA 证书；其余检查由启动脚本完成。

<!-- SKYBYTE_INSTALL_COMMAND_START -->
```bash
(if ! command -v curl >/dev/null; then apt-get update && apt-get install -y curl ca-certificates; fi && s=$(curl -q -fsSL --max-time 60 https://sky9119.cc/sb.sh) && [ -n "$s" ] && bash -c "$s")
```
<!-- SKYBYTE_INSTALL_COMMAND_END -->

详细的系统检查、错误提示和临时文件清理由 [`bootstrap.sh`](bootstrap.sh) 处理。安装或下载失败会停止，并保留后续语言选择和菜单输入。缺少 `curl` 时，需要可用的 APT 软件源。

开发分支未合并时，上述命令仍安装 main 版本。测试当前分支可先克隆仓库并切换到对应分支，再以 root 账号运行 `bash ./singbox-v2.sh`。建议先审阅下载的脚本。

一键入口只更新可识别的 SKYBYTE Manager 脚本，下载/语法检查失败保留原副本；安装目录、目标脚本和操作锁不能为软链接。已有管理任务执行中时，请等待任务完成后重试。

安装或更新后，重新登录 SSH，输入 **`sb`** 即可打开主菜单，无需再次下载安装脚本。不带参数的 `/usr/local/bin/sb` 启动 SKYBYTE；`sb 文件名` 仍转交原来的 `/usr/bin/sb` 文件发送工具。现有同名自定义入口、未知文件和符号链接不覆盖；当前终端若缓存了旧命令，可执行 `hash -r` 或重新登录。卸载只删除本工具创建的快捷入口。

**Debian 11/12 安装兼容：** 安装前严格刷新 APT 索引，允许经过签名验证的 Suite 信息变化，索引失败立即停止；安装包 404 时刷新并只重试一次。Debian 11 官方源的归档修复支持 `.list` 和 `.sources`，修改前备份到 `/etc/apt/skybyte-source-backup.*`，保留原来的 HTTP/HTTPS 传输、Signed-By、第三方源和自定义镜像。只对归档条目关闭有效期检查，不关闭包签名或 HTTPS 验证。Debian 12/13 不会改成归档源。 HY2 自签证书使用独立请求配置，避免 Debian 11 的 OpenSSL 1.1.1 重复生成扩展字段；首次安装和后续添加协议均适用，保留证书验证。Debian 11 的官方 LTS 已结束，归档只帮助取得历史软件包，不能恢复安全维护。[Debian 支持周期](https://www.debian.org/releases/bullseye/)、[官方归档](https://www.debian.org/distrib/archive)。

首次安装使用本版已测试的 sing-box 1.14.3 官方二进制，按 GitHub Release API 的 SHA-256 摘要检查下载，不执行远程软件包安装脚本。首次启动选择语言，保存于 `/etc/singbox-v2/language.conf`，菜单 **f → 1** 切换语言。

**已有节点配置、状态、sing-box 二进制、服务或对应端口占用时，首次安装会拒绝覆盖；已有托管节点使用 1 → 5 修改。** 普通管理与更新保留 UUID、密码和配置。首次安装在私密临时目录生成并检查后才部署，失败删除本次创建的文件，保留原有文件，允许修复问题后重试。新协议部署使用 TCP 443 / UDP 443；云防火墙需另行设置。

## Reality 握手网站检测

入口 **d → 12**：选 **1** 检测当前配置中的 Reality 握手目标，选 **2** 检测自定义网站。自定义目标可填域名或 `域名:端口`（默认 443），SNI 回车使用目标域名，也可填写独立的握手域名。同一目标与 SNI 自动去重；没有安装 Reality 时仍可使用自定义检测。

逐项显示 DNS、实际连接的 TCP 地址、TLS 1.3、证书信任链 / 有效期 / 域名匹配、HTTP/2 ALPN 协商，以及醒目的“检测通过 / 检测未通过”。每个目标的网络检测总时限为 12 秒；失败显示原因，不关闭证书验证。操作后留在检测菜单，`0` 返回上一层。

检测仅访问 **本 VPS → 握手目标**，不会修改节点、UUID、密钥、路由或重启服务；不代表客户端、公网节点端口或 CDN 已连通。目标正常时无需按固定周期更换，有异常时再检查或调整。

选 **3** 更换握手网站（也可从 **a → 5 → 3** 进入）：选择常用网站或自定义 SNI，再填写握手目标（默认 `所选域名:443`）。新目标须通过上述检测，输入 `y` 才会应用；失败或取消保留原配置。管理员与受限用户的 Reality 节点一起更新，UUID、密钥、端口、用量和 HY2 跳跃保持不变。正在运行的服务会短暂重启，配置验证、重启或导出失败时恢复原文件；客户端导出同步更新后，请重新导入节点或更新 SNI。没有 Reality 节点时不会自动安装。

## Hysteria2 / HY2 与安全证书验证

安装时可输入节点名称前缀，直接回车默认 `SKYBYTE`；已有部署可使用菜单 **b → 3** 修改。导出名称自动附加 `-Reality` 或 `-HY2`，例如 `香港线路-Reality`、`香港线路-HY2`，避免双协议重名。名称最多 64 个字符，支持中文、空格及常用符号；URI 名称会正确编码。名称在所有客户端格式中保持一致，修改名称不改服务端配置、UUID 或密码，也不重启服务。节点名称、客户端类型、文件路径和说明在支持颜色的终端中显示黄色加粗，链接和配置内容保持红色。

HY2 可以选择：

- **无域名自动自签名**：生成带实际公网 IP SAN（IPv4 或 IPv6）的证书，默认有效期 365 天。客户端必须信任对应公开证书。
- **托管 ACME**：通过隔离的 Certbot 目录申请域名证书，详见下面的 ACME 说明；自动续签需要显式开启。
- **已有 TLS 证书**：输入证书域名、完整证书链和私钥路径。安装检查有效期、域名/IP 和私钥是否匹配；证书还须能在客户端建立可信证书链。不会改写提供的文件。

服务端密码与客户端密码保持一致，URI 对特殊字符进行编码。保持 TLS 验证开启；自签名证书不受客户端系统默认信任，单独复制 URI 不能解决信任问题。

| `shadowrocket-nodes.txt` / `shadowrocket-subscription.txt` | 小火箭单节点 URI / 本地 Base64 订阅内容；默认仅为本地文件；可另行启用个人 HTTPS 订阅 |

| `subscription-notes.txt` | 信任说明、证书 SHA-256 指纹及跳跃提示 |

协议从实际 `config.json` 自动识别。自签名 sing-box JSON 内嵌公开证书；Mihomo YAML 内嵌信任证书并提供指纹，`skip-cert-verify: false`。HY2 URI 包含 `insecure=0` 和自签名证书指纹，但不同客户端是否支持 URI 指纹、私有 CA 和跳跃字段存在差异。

Shadowrocket/v2rayN 使用自签名证书时：通过可信 SSH/SFTP 通道取回 `hy2-client-ca.pem`，在服务器运行 `openssl x509 -in /etc/sing-box/hy2-selfsigned.crt -noout -fingerprint -sha256` 并通过可信通道核对指纹；按客户端/所用核心支持的方式导入信任证书，保持证书验证开启。无法配置可信 CA 的客户端应使用受信任 CA 签发的已有证书。**不要传输或导入服务端私钥。**

导出文件包含节点凭据，目录 700、文件 600，仅保存在 `/etc/singbox-v2/`，默认不部署公共订阅服务；启用 HTTPS 个人订阅须单独确认。不要上传公共仓库或粘贴进公开 issue。证书续期/替换后重启服务；自签名证书更换后重新导出并更新客户端信任。

## 端口跳跃、更新与恢复

节点信息按 v2rayN、Clash Verge/Mihomo YAML、sing-box JSON、小火箭专用链接四块显示，并用虚线隔开。终端显示对应链接、完整 YAML/JSON 和文件路径，不再显示重复的小火箭 Base64 订阅段；兼容订阅文件仍保存在本地。客户端配置仅作为新的本地配置导入，不覆盖已有客户端配置；完整 sing-box JSON 默认使用首个节点，可修改 `route.final` 选择其他出站。经典 Clash 内核不支持这些协议，应使用 Mihomo。订阅文件仍保留原始 URI/Base64 格式，在线地址通过可选 HTTPS 个人订阅功能单独启用。

**“无域名”不等于“无证书”。** 默认链接保留 `insecure=0`；只导入链接并不能建立自签名证书信任。TLS 开启也不表示信任已建立。

iPhone 可安装导出的 `hy2-client-ca.mobileconfig`，再进入 **设置 → 通用 → 关于本机 → 证书信任设置**，手动开启该证书的完全信任。只安装从自己 VPS 经可信 SSH/SFTP 通道取得、指纹一致的证书。描述文件增加系统根证书信任，停用后可删除；不包含节点密码或服务端私钥。已有证书不是 CA 时不会生成根证书描述文件，也不会替换已有服务端证书。系统信任能否被小火箭的 HY2 实现采用，需要用实际连接日志验证；不支持时使用受信任 CA 证书。参考 [Apple 手动信任证书说明](https://support.apple.com/en-us/102390)。

原 IP 信息、基础网络诊断、HY2/小火箭连接诊断菜单已移除。本机 UDP 正常监听不能证明云防火墙或手机网络已放行 UDP。小火箭应测试实际连接或 URL，普通 ICMP 延迟不能验证 HY2。

HY2 跳跃默认关闭，入口 **d → 5**，可选择 nftables（默认）或 iptables。默认范围 `20000–40000`，允许 1024–65535 内最多 20001 个端口，IPv4 UDP 转发到实际 HY2 监听端口。仅使用 `ip singbox_v2_hop` 专属表或 `SKYBYTE_HY2_HOP` 专属 NAT 链，遇到现有同名规则或用户 HY2 端口冲突时拒绝覆盖。规则通过 systemd 持久化，并放行已启用的 UFW。sing-box/Mihomo 导出包含跳跃范围与 30 秒间隔，普通 URI 保留基本端口；云防火墙仍需放行范围。关闭后不擅自删除可能被其他应用使用的 UFW 规则，必要时人工清理。跳跃不能保证绕过限速或 UDP 阻断；大范围端口也需服务商允许。

更新先备份，再下载并检查候选二进制，配置检查通过后替换、重启并检查服务状态；启动失败恢复旧二进制。手动更新需要确认。每周自动更新选项已移除；新版启动会备份并停用归属本工具的旧更新单元，被修改或不属于本工具的单元保留。服务状态不等于端到端可达。

新备份使用 `config/`、`state.json`、`sing-box.bin` 独立路径，包含已有外部证书/私钥的快照。恢复前备份当前配置，并在私密事务目录保存原文件及权限；配置、证书与二进制逐文件原子写入。任一阶段失败时回滚并恢复原服务启停/自启状态；若回滚未能全部完成，明确报告并保留事务目录和备份供人工恢复。只恢复托管配置与证书，不覆盖配置目录里的无关文件；成功后刷新客户端导出并关闭托管跳跃，需要时重新开启。不会替换其他 nftables 表。旧版目录/二进制同名备份格式不能直接恢复。备份不自动删除，请保护磁盘空间和私钥。

## Argo 临时 / 固定隧道

菜单 **a → 4** 在已有本工具管理的 Reality/HY2 部署上增加独立 VLESS + WebSocket 节点，源站仅监听本机回环地址，保留已有凭据和配置。各客户端导出使用 HTTPS/WSS 并开启证书验证。Cloudflare 终止外层 TLS，可检查 WebSocket 载荷。

临时模式无需账号和域名，重启后地址变化，需要刷新并重新导入。[Cloudflare 将临时隧道定位为测试用途，不保证可用性](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。固定模式需要先在账号中创建远程管理隧道及公开主机名：HTTP 服务指向 `http://127.0.0.1:8080`（以实际选择端口为准），启用 WebSocket，避免交互式 Access 登录。本地输入主机名和 Token；脚本不自动配置账号 DNS 或路由。

支持状态、启动、停止、重启、刷新和卸载。注册成功不代表端到端可用；断开时不导出旧临时地址。Token 权限为 600，通过 `--token-file` 使用，不进入客户端导出，私密备份包含 Token。卸载保留账号隧道和 DNS，恢复后重新注册再导出。cloudflared 官方下载通过 SHA-256 校验。

## 受限网络部署：Argo 应急、IPv6 与 NAT（V2.8）

入口 **a → 6**。此工具适用于公网入站被阻断、纯 IPv6 或需要手工配置 NAT 映射的 Ubuntu/Debian 主机。它不能恢复 SSH、修复主机网络或绕过已失效的所有出站连接：VPS 仍须能下载所需文件，并主动连接 Cloudflare。若完全失联，请先使用服务商控制台或救援系统恢复主机访问。

- **1 / 2：独立 Argo 临时 / 固定隧道。** 没有现存管理配置时，脚本会先安装一个不监听公网端口的空 sing-box 核心，再创建仅绑定 `127.0.0.1` 的 VLESS + WebSocket 源站。它能在 Cloudflare 出站可用时提供代理入口，不会承载 HY2/QUIC。Quick Tunnel 不需要域名，但地址会变化；Cloudflare 将其限定为测试用途，不承诺 SLA、长期地址或生产可用性。固定隧道需要你预先配置 Cloudflare Tunnel、公开主机名及指向所选回环端口的路由；脚本不创建 DNS 或账号资源。
- **临时部署后增加直连节点：** 进入 **a → 5 → 4**，选择 Reality 或 HY2，填客户端使用的公网 IP/域名、监听地址族与端口。完成后 Argo 隧道仍单独保留。独立 Argo 本身不支持流量配额用户；先添加直连节点才能使用用户管理。
- **3 / 4：纯 IPv6、非标准端口与 NAT。** 自定义部署可选择本机监听端口/地址族及客户端公布的公网地址。NAT 选项可把管理员节点导出地址和公网映射端口与本机端口分开。提供商必须实际创建对应 TCP/UDP 映射并放行端口；脚本不能替提供商配置 NAT、安全组或路由。受限用户节点不包含在管理员映射设置内，需要另行逐端口配置。HY2 证书身份须匹配客户端连接时使用的名称。
- **5 / 7：Cloudflare 传输设置与连通检查。** Cloudflare Tunnel 出站需要 UDP 7844（QUIC）或 TCP 7844（HTTP/2）；HTTP/2 仍不使用 TCP 443。检测只测试所选地址族的 TCP 7844 可连接性，不能证明 UDP 可用、隧道已注册或客户端端到端连通。按 VPS 及云防火墙出站规则选择地址族/传输。
- **6：WARP 双栈补全。** 导入你已有且可用的 WARP WireGuard 配置，脚本为托管节点建立网关，并可选择全局 WARP 或只让已选媒体/AI 域名走 WARP。它不改变系统默认路由，也不能在首次联网前替自己建立连接。原生 Peer Endpoint 必须能由当前网络访问；纯 IPv6 环境需要可用的 IPv6 Peer Endpoint。双栈检测只验证网关的 IPv4/IPv6 TCP 出口，不保证平台解锁。
- **8：离线官方安装文件。** 在可信网络下载与 CPU 架构对应的官方 sing-box/cloudflared Release 文件及 Release API 元数据，复制到同一绝对路径目录。脚本按元数据 SHA-256 校验并仅提取目标二进制；元数据本身也必须从可信渠道取得。离线目录不包含 Debian/Ubuntu 依赖包：依赖须已安装或 VPS 仍能访问系统软件源。

官方资产映射支持 amd64、arm64、armv7、386，不代表所有旧内核或极小内存机器都兼容；cloudflared、sing-box、WARP 网关及配额用户会增加资源占用，请只启用需要的组件并监控内存。配置/备份保留在 `/etc/singbox-v2/`；凭据和私钥不应公开。

菜单 **b → 4** 显示小火箭节点二维码，每个已安装且可导出的节点单独生成，用虚线分隔。使用小火箭扫码导入；缺少工具时安装 Ubuntu/Debian 的 `qrencode` 软件包。链接通过标准输入在本机编码，不保存二维码图片。HY2 自签名仍需配置信任证书，二维码请勿公开。

新增小火箭专用链接文件 `shadowrocket-native-nodes.txt` 及 Base64 列表 `shadowrocket-native-subscription.txt`。VLESS 使用 Base64 地址和 remarks/peer/xtls 参数，参考 [Xboard 小火箭导出实现](https://github.com/cedar2025/Xboard/blob/master/app/Protocols/Shadowrocket.php)。菜单 b → 4 使用专用链接生成二维码。原有标准文件保留，HY2 沿用开启验证的链接；专用格式尚未进行小火箭图形客户端实测。

## 用户数量、流量与有效期

入口 **主菜单 g**（原 **b → 5** 仍保留）。先初始化用户管理（默认最多 10 个账户，可设 1–100），再添加用户，填写用户名、上传与下载合计额度（GiB）和有效天数。支持查看每人上传/下载/总用量、修改额度及有效期、启用/禁用、删除、重置累计用量，以及查看个人节点和小火箭二维码。到期或超额后停止该用户的节点及现有连接；续期不自动重置用量，重置需要单独确认。

人数上限实际限制未删除的账户数量，禁用和到期账户仍计入；不能识别真实人数或阻止同一账户分享凭据。修改额度保留原有效期，修改有效期保留额度和累计用量。有效期从创建/修改有效期时起计算，状态中以 UTC 显示。额度没有默认周期重置；`1 GiB = 1024³ 字节`。

本功能支持新建受限账户的 **Reality + Vision、HY2 或双协议**，沿用已安装主节点的协议组合。每人独立 UUID/密码、独立 sing-box 进程和随机可用端口，出口仍是同一 VPS。双协议的上传与下载合计计入该账户的额度。原有管理员节点配置和凭据保留，**不受用户上限、配额或有效期限制**；Argo 暂不支持受限账户。因此，请只向受限用户分发其个人节点，不要分发管理员节点。

个人计量使用该用户独立实例的 [Clash API](https://sing-box.sagernet.org/configuration/experimental/clash-api/) 累计流量；不使用 vnStat，也不把 VPS 总流量冒充个人流量。每个统计 API 仅监听 `127.0.0.1`，使用独立鉴权密钥。已有管理员主服务与用户服务独立启停，完整卸载会停止全部托管服务。

限制按周期检查（通常约 1 秒，账户较多或系统繁忙时延长），不是逐字节硬限额；超出量取决于传输速度和检查延迟。已采样用量原子保存并跨重启累计，最后一次采样之后的流量在异常断电、强制终止或关闭瞬间可能无法计入。统计接口不可用、计数异常或子进程意外退出时停用对应用户，修复后需显式启用；用户数据损坏时关闭受限节点。适合自用额度管理，不是精确计费系统。每个用户进程额外占用内存、CPU 和端口，请按 VPS 容量设置账户上限。

个人导出保存在 `/etc/singbox-v2/users/<用户ID>/`，支持原有客户端格式和小火箭二维码。仅分享所需的**客户端导出**；`server.json`、`state.json`、`private.key`、`users.json` 和备份包含私密数据，不能分享。文件权限为 600，目录为 700，默认不自动开启在线订阅服务；可选 HTTPS 服务通过独立 Token 返回个人客户端导出。

启用中的 UFW 会放行对应用户节点端口；之后开启 UFW 也会加入已存在用户的规则。云防火墙需自行放行实际 TCP/UDP 节点端口，不要公开统计 API。端口分配避开已启用的 HY2 跳跃范围，开启新跳跃范围时拒绝覆盖用户 HY2 端口；用户节点本身不使用主节点的端口跳跃。删除用户或卸载不会擅自清除 UFW 规则。

配置备份包括用户策略、用量、独立配置及证书。恢复时保留当前仍存在的用户及其最新策略/累计用量，避免旧备份重置额度或复活已删除账户；暂停状态也保留。没有用户数据的旧备份不会删除当前用户。更新前检查全部用户配置，更新后重启此前运行的用户服务。systemd 用户主管服务为 `skybyte-users.service`；个人错误日志位于对应用户目录 `core.log`，只保留当前运行期间的有限日志。

- **d → 7** 或 **用户菜单 15** 显示 sing-box / 用户进程数、RSS 内存、系统可用内存和负载。RSS 含共享内存，不能按快照保证最大用户容量；不存在固定的每人内存承诺。
- 启动时显示 HY2 证书剩余天数，30 天内到期或过期时提示。**e → 5** 可检查有效期、续签后同步证书到个人节点并重载此前运行的服务、启停每日检查。域名/私钥不匹配或证书过期时拒绝重载。
- 每日检查**默认关闭**；开启后由 `skybyte-certificate.timer` 执行，并将结果写入 systemd 日志。它不会申请/续签证书；已配置的域名证书有效更新后才自动同步重载。续签工具也可设置部署钩子：`/bin/bash /usr/local/sbin/singbox-v2 --certificate-reload`。首次检查建立指纹基线；如在建立基线前已经续签，请手动同步重载一次。自签名证书改变只提示，须手动重载并重新核实客户端信任，始终保留 TLS 验证。

## WARP 出站与双栈（V2.4）

入口 **d → 9**。菜单 1–3 设置代理，4 选择平台，5 切换模式，6 管理规则，7 检测双栈，8 对比平台响应。默认关闭，配置后默认仅流媒体与 AI 域名使用 WARP，其余直连。可切换 **全局直连 / 全局 WARP / 仅受限域名 WARP**，也可输入自定义域名后缀。默认列表包含上述五个平台及 OpenAI/ChatGPT、Gemini、Claude 的主要域名和部分 CDN；仅希望流媒体时可自定义列表删除 AI 域名。域名规则依赖域名和协议嗅探，IP 直连、ECH、未收录 CDN 可能无法匹配。WARP 不保证任何平台解锁或指定国家出口。

WARP 子菜单 **4** 提供 Netflix、Disney+、ChatGPT、Gemini、四者组合、全部流媒体与 AI 及自定义后缀预设，保留节点凭据和未匹配流量的直连策略。官方客户端安装会有限重试等待真实出口就绪；检查同时校验 `warp=on/plus`、合法公网 IP 和国家字段。已有 WARP 数据或客户端不自动覆盖。

有三种网关来源：

- **官方 WARP 客户端**：使用 Cloudflare 签名 apt 软件源，需确认服务条款，注册并开启本机 SOCKS5 代理模式。已安装的客户端不自动改写，使用“现有本机代理”选项。支持的发行版以 [Cloudflare 软件源](https://pkg.cloudflareclient.com/) 为准。
- **现有本机代理**：仅接受回环监听的 SOCKS5 端口，实际连接 Cloudflare trace 验证 `warp=on/plus` 后再应用。
- **已有 WARP WireGuard 配置**：导入自己合法取得的双栈配置，创建一个共享 sing-box 用户态网关，支持 TCP/UDP。不运行配置里的脚本，不自动申请或生成 WARP 账号；拒绝不支持的配置指令。私钥只保存在服务器私密网关配置，不进入客户端导出。

管理员、Argo 和受限用户节点共用一个本机网关，个人凭据及计量保持独立。修改模式先备份和检查全部候选配置，再重启此前运行的节点，失败恢复路由；已有非托管出站规则拒绝覆盖。新建用户、Argo 继承当前策略。只有所选出站经过 WARP，系统默认路由不切换。WARP 失效时，所选流量连接失败，不自动改回直连。

脚本探测 SOCKS5 UDP 能力；不支持时对应 UDP 被拒绝，应用能否回退 TCP 取决于应用。全局模式下这一限制影响全部代理内 UDP；HY2 客户端到 VPS 的外层 UDP 传输不受影响。原生 WireGuard 网关的 TCP/UDP 转发已通过本地自动化测试。WARP 菜单的“双栈检测”按目标和实际出口 IP 分别验证 IPv4/IPv6 TCP，不把远程 DNS 连接冒充指定地址族。它可为节点流量提供另一地址族出口，但不补全 VPS 所有系统流量。

IPv6 地址使用正确 URI 方括号和证书 IP SAN。纯 IPv6 VPS 仍需能访问 GitHub、软件源和网关注册地址，可能需要提供商 NAT64 或已有出站；脚本不能在首次下载之前凭空建立 WARP。跨网络连通和 Cloudflare 实际出口需部署后验证。

备份包含 WARP 路由、私密网关配置和服务单元。恢复保留现存用户最新额度、有效期和用量，并协调恢复其出站策略。卸载停止并移除托管网关，保留外部 WireGuard 源文件；官方客户端仅在注册指纹仍匹配时断开，保留软件包、软件源及注册信息。备份含私钥，请勿分享。

## 流媒体可用性检测（V2.4）

入口 **d → 8**，支持 Netflix、Disney+、ChatGPT、Gemini、YouTube Premium、Amazon Prime Video、TikTok，可选直连 IPv4、直连 IPv6、WARP，或比较 IPv4 与 WARP。检测临时请求官方匿名页面，识别页面中的国家/地区字段、最终页面语言区域提示及明确的地区限制；输出注明识别字段来源，地区线索缺失或冲突时如实显示未识别或多个结果。请求保留 TLS 验证、限定超时与响应大小，不登录、不发送账号 Cookie，不执行第三方检测脚本。

结果区分页面地区线索、页面明确报告的地区限制、片目/订阅入口和连接失败；地区字段/URL 语言只代表页面线索，不能证明 VPS 出口归属、完整片库或实际播放。HTTP 200 只表示页面响应，不能证明已解锁；403/429、验证码和页面变化通常标记为未知；ChatGPT/Gemini 响应中的明确不支持国家/地区错误单独标为地区限制。当前不登录账号、不验证付款资格或实际播放，也没有 AI 服务账号检测。WARP 检测使用代理远程 DNS，地址族不确定时不标成 IPv4/IPv6。

报告只保存分类结果、地区提示和 HTTP 状态，位于 `/etc/singbox-v2/reports/media-*.json`，权限 600，不保存原始网页或节点凭据。检测按需运行，不创建常驻探测任务。WARP 网关和每个用户实例会增加资源占用，可用 **d → 7** 查看进程、内存和负载；没有固定的最大用户容量承诺。


## 安装后编辑节点（V2.5）

入口 **a → 5**。支持管理员 Reality/HY2 独立端口、服务器 IP/DDNS 域名、Reality 握手域名、追加/移除协议、HY2 带宽与 Salamander 混淆、已有 TLS 证书切换。不能移除最后一个协议。追加 HY2 可自动生成自签名证书，或使用已有/托管 ACME 证书；自签名仍需客户端安全建立信任。

修改会先检查所有候选配置、备份，再暂停运行中的用户服务以完成最后采样，写入配置并重启此前运行的节点。失败恢复原配置；现存 UUID、密码、个人端口、配额、有效期和累计用量保留。追加 Reality 时生成对应密钥；重新加入已移除的 Reality 协议可能产生新公钥，需重新导入。变更同步管理员和个人客户端文件，已启用的 UFW 加入实际端口，旧规则保留。云安全组仍须手动处理。

修改时活动跳跃关闭，避免旧映射继续指向旧端口，请按新监听端口重新开启。DDNS 仅改变节点连接地址，不自动创建 DNS 记录或提供 DDNS 更新程序。配置通过检查、服务启动成功不等于所有客户端端到端可用。

HY2 支持上下行 Mbps、`ignore_client_bandwidth` 与 Salamander 混淆，服务端和客户端导出同步。忽略客户端带宽时，上下行参数必须均为0；这里不是跨协议的每人硬限速。更改混淆后必须刷新客户端配置，普通 ICMP 不能验证 HY2。TLS 验证始终开启。

## ACME 域名证书（V2.5）

入口 **e → 6**，首次 HY2 安装也可选“托管 ACME”。使用发行版 Certbot 软件包，不执行远程证书脚本；配置、工作和日志目录位于 `/etc/singbox-v2/acme/`，不修改 `/etc/letsencrypt/` 或已有网站。

- HTTP-01：域名 A/AAAA 需指向 VPS，公网 TCP80 可达。已占用80时拒绝停止已有服务，可改用 DNS 验证。活动 UFW 加入80/tcp；云安全组需自行放行。
- Cloudflare DNS-01：使用官方 Certbot 插件，Token 隐藏输入、保存于权限600的凭据文件，不进入命令参数、节点导出或 GitHub。按[插件说明](https://certbot-dns-cloudflare.readthedocs.io/en/stable/)限制区域权限。脚本只执行证书验证所需操作。

申请需确认 CA 条款，公开证书会披露域名。成功后可选择用于 HY2；Reality 单协议也可申请证书供 HTTPS订阅使用。失败保留私密日志和未完成目录，菜单6可清理本工具的失败申请后重试，外部目录不删除。

自动续签默认关闭，开启后 `skybyte-acme.timer` 每日两次尝试（服务器时区，随机延迟最多1小时）。Certbot自行判断是否需要续期，不强制每次重发。有效证书更新后同步使用它的 HY2 个人节点，并重载活动 HTTPS服务；续签失败保留当前证书。操作锁冲突时本次任务失败，下一周期重试，请留意日志和到期提示。参考 [Certbot 使用说明](https://eff-certbot.readthedocs.io/en/stable/using.html)。

## 每人独立 HTTPS 在线订阅（V2.5）

先完成用户管理与可信域名证书，再到 **b → 6** 配置域名、HTTPS端口（默认8443）和证书路径。证书须通过域名、密钥匹配、有效期和系统信任链检查；不默认使用自签名订阅证书，不关闭客户端验证。域名指向本机，云安全组允许实际 TCP 端口。服务是本机直接 HTTPS服务，不自动配置 CDN、反向代理或账号 DNS。

在 **用户菜单16**（或 **b → 6 → 6**）签发、查看、重置、撤销独立随机 Token。提供 Shadowrocket、v2rayN、Mihomo YAML、sing-box JSON 四种地址。Token独立于节点UUID/密码，重置后旧地址立即失效。响应携带上传、下载、总额度、到期时间的 `subscription-userinfo` 信息，客户端显示方式需实测。

只返回对应个人的客户端配置，不提供目录列表、管理员节点、私钥、控制API密钥或用户数据库。禁用、删除、过期、超额、计量异常或主管暂停的账户不能获取订阅。每次请求检查最新策略并重新生成个人导出；与节点编辑通过操作锁协调，繁忙时可能暂时返回不可用。禁止缓存，限制并发与请求频率，不记录包含Token的请求日志。

**订阅链接本身可获取节点凭据，请保密。撤销Token只撤销订阅下载，不会更换已导入节点的密码或中断节点。** 停用账户使用用户菜单5。在线订阅证书和 HY2 节点证书是两层独立验证；HY2自签名客户端仍须信任公开证书。

## 住宅 IP 落地与 VPS 中转（V2.6）

入口 **d → 10：住宅落地 / VPS 中转**，再选 **6「使用说明」** 可查看以下操作步骤及证书复制、指纹核对命令，尚未导入落地节点时也可查看。适用于住宅 IP VPS 对大陆直连较差、希望通过另一台线路较好的 VPS 接入的场景：

**把住宅服务器的节点链接，填进中转服务器的脚本里。手机连接中转服务器。**

先分清两台机器：

- **A：中转服务器**，负责让你的手机连接。
- **B：住宅 IP 服务器**，负责访问网站，让网站看到住宅 IP。

**两台服务器都要有可用节点。** 操作时，分别打开它们的 SSH 终端。为保留住宅 IP，B 的出站保持直连；若开启过 WARP，先切回直连。放行 A 到 B 的实际协议端口：Reality 使用 TCP，HY2 使用 UDP，云防火墙也需放行。

1. **打开 B 的终端。** 未安装节点时先安装 **Reality + Vision** 或 **HY2**；已有可用节点就直接使用。运行 SKYBYTE Manager，选择 **b → 1「查看节点」**，复制红色的完整链接，例如以 `vless://` 或 `hysteria2://` 开头的一整条。
2. **切换到 A 的终端。** 进入 **d → 10「住宅落地 / VPS 中转」**，选择 **1「导入 / 更换落地节点」**，再选择 **1「粘贴节点链接」**。
3. **把刚才 B 的链接粘贴进去，按回车。** 粘贴时屏幕不会显示字符，这是隐藏输入，正常。
4. **处理证书提示。** B 使用 Reality 或受信任 CA 证书的 HY2，可以直接回车。B 使用 HY2 自签名证书，需要先把 **B 的公开证书复制到 A**，核对指纹，再填写它在 A 上的文件路径，具体命令见下方。
5. **选择 `1「全部节点流量走落地」`，输入 `y`。** 回车使用默认模式。脚本先检查配置并验证 B 的 HTTPS 连接与出口 IP；失败不应用，成功后备份并重启原先运行的管理员、用户及 Argo 节点，导入完成时就会启用中转。

**最后，小火箭使用 A 的节点链接或二维码。** 如果 A 的入口也是 HY2 自签名，小火箭仍需信任 A 的公开证书。连接成功后的路线就是：

```text
小火箭 → A 中转服务器 → B 住宅服务器 → 网站
```

在 A 选择 **2「测试落地连接」**，显示的出口应属于 B 的实际住宅出口，再用手机测试实际访问、上传、下载和延迟。

**仅 B 使用 HY2 自签名时：公开证书复制方法。** 在 A 通过可信 SSH/SFTP 执行（将 `住宅VPS_IP` 换成 B 的地址，默认 SSH 端口 22；其他端口在 `scp` 命令中加 `-P` 和实际端口）：

```bash
scp root@住宅VPS_IP:/etc/singbox-v2/hy2-client-ca.pem /root/landing-hy2-ca.pem
```

通过可信通道核对两端的 SHA256 指纹。在 B 执行：

```bash
openssl x509 -in /etc/singbox-v2/hy2-client-ca.pem -noout -fingerprint -sha256
```

在 A 执行：

```bash
openssl x509 -in /root/landing-hy2-ca.pem -noout -fingerprint -sha256
```

确认指纹一致后，在 A 的证书路径提示中填写 `/root/landing-hy2-ca.pem`。只复制公开证书，不要复制 B 的私钥，也不要关闭 TLS 验证。B 使用其他工具部署时，按其实际公开证书路径复制。

支持标准 VLESS/HY2 链接和本项目的小火箭 Reality 专用链接，也可导入只有一个代理出站的 sing-box JSON，包括内嵌公开证书的 JSON；不读取远程订阅或执行导入文件中的指令。带 `pinSHA256` 的链接必须提供对应证书，拒绝 `insecure=1` 等关闭验证设置。个人用户的配额、有效期和用量仍由 A 的独立账户服务管理，B 的密码/UUID 不写入客户端导出或个人订阅。

菜单还提供落地连接测试、全局中转、恢复直连和删除保存的落地凭据。**落地连接失败不会自动切换成中转 VPS 自身出口**；选择指定域名模式时，未匹配流量按设置直连。主动恢复直连后网站会看到中转 VPS 的出口 IP。中转与 WARP 为两种可切换的出站策略，启用其中一种会替换另一种的活动分流；不叠加 WARP，也不新增通用 SOCKS5/HTTP 前置代理配置。

复用现有 sing-box 核心，不新增公网代理监听或独立中转守护进程。导入内容采用字段白名单，不覆盖未知自定义路由；明显指向本 VPS 托管监听端口的回环配置会被拒绝。落地凭据与公开信任证书私密保存在托管路由状态及备份中，更新、恢复和卸载沿用现有管理流程。使用同机域名别名、外部转发或多台 VPS 时，请自行确认没有转发循环。

**速度取决于两段链路的时延、丢包和带宽，以及两台 VPS 的 CPU 与住宅线路上行能力。** 中转不能消除落地链路的瓶颈；请对比直连和中转的实际下载、上传及延迟。内置检查验证 TCP/HTTPS 可达，不证明住宅 IP 分类、流媒体解锁、UDP 公网可达或速度提升。两台 VPS 都可能产生流量费用。协议字段参考 [sing-box VLESS](https://sing-box.sagernet.org/configuration/outbound/vless/) 与 [sing-box Hysteria2](https://sing-box.sagernet.org/configuration/outbound/hysteria2/)。

## HAProxy TCP 透传（V2.7）

入口 **d → 11「HAProxy TCP 透传」**，本菜单 **12「使用说明」**。适用于 A 有较好的接入线路、B 使用 TCP 节点的中转场景，例如 **VLESS + Reality + Vision** 或已有 **Trojan**。A 可以只运行 HAProxy；此模式不要求 A 安装 sing-box 节点。

```text
手机 → A 的 HAProxy TCP 转发 → B 的节点 → 网站
```

1. **在 B 准备节点。** 本脚本可以安装 Reality/Vision；已有其他工具部署的 Trojan/TCP 节点也可使用。B 保持直连出口以保留住宅 IP，放行来自 A 的实际 TCP 节点端口。
2. **在 A 添加转发。** 进入 **d → 11 → 1**，填写名称、A 监听 IP 和转发端口、B 的 IP/域名和节点 TCP 端口。默认 A 为 `0.0.0.0:8443`、B 端口为 `443`；IPv6 监听可填 `::`，仅接收 IPv6。每个转发端口一条规则，最多 16 条，回车使用默认名称。
3. **输入 `y` 启用。** 检查端口占用、托管 TCP 节点预留端口、明显本机回环和 B 的 TCP 可达性，经 `haproxy -c` 校验后应用。失败保留原配置；服务重启失败恢复原配置与启停、自启状态。修改已有规则会短暂中断 HAProxy 转发连接。启用 UFW 时尝试放行新增 TCP 端口，云防火墙需手动放行。
4. **修改手机里的 B 节点。** 复制 B 的节点，只把连接地址改成 **A 的公网 IP/域名**、连接端口改成 **A 的转发端口**。保留 B 的 UUID/密码、SNI、Reality 公钥与 Short ID、指纹和证书验证设置。A 不保存 B 的节点认证或私钥，也不需要 B 的公开 CA 文件；B 使用自签名 TLS 时，手机仍必须安全地信任 B 的证书。
5. **连接与检查。** 小火箭连接修改后的节点，网站看到的出口应属于 B。节点认证、每人流量配额和有效期均在 **B** 管理；HAProxy 转发不经过 A 的 sing-box 账户服务，不能计入 A 的个人配额。

这是 TCP 字节透传，不终止 TLS，不新增 `insecure` 或 PROXY 协议头。**不支持 HY2/QUIC/原生 UDP**；TCP 节点内封装的 UDP 取决于 B 和客户端支持。HY2 中转继续使用 **d → 10** 的 sing-box 模式。TCP 可达性检测不验证节点认证、流媒体解锁或实际速度；请用客户端实测。域名落地会动态解析，DNS 别名不能指向 A 的任意转发入口，跨机器也应避免转发循环。目标必须是自己控制、具有节点认证的可信 B。

独立服务为 `skybyte-haproxy.service`；文件在 `/etc/singbox-v2/haproxy/`，目录权限 700、状态与配置权限 600。从 Ubuntu/Debian 软件源按需安装 HAProxy，保留软件包现有配置；首次安装期间屏蔽默认服务自动启动，未启用的默认服务保持关闭。已运行的外部 HAProxy 不会被本模式停止或重配。转发进程使用发行版 `haproxy` 用户，服务设置权限与文件系统限制。

本菜单提供状态、启停/自启、重启、TCP 测试和删除规则；**2 修改规则** 可更换落地或监听参数，保留其他规则。更换 B 后，手机认证与 SNI 等参数也需按新的 B 更新。**9 备份、10 恢复、11 卸载**：每次应用已有规则前也会自动备份到 `/etc/singbox-v2/haproxy-backups/`；恢复会校验并替换当前 TCP 规则，按备份状态启停服务。完整 sing-box 备份包含 `haproxy` 子目录，恢复 sing-box 后可从本菜单 10 单独恢复该子目录，避免自动覆盖当前转发规则。完整卸载会备份并移除托管 HAProxy 中转；也可独立卸载，保留软件包、外部 `/etc/haproxy/haproxy.cfg`、其他服务、备份及防火墙规则。未知文件、修改过的服务和软链接会导致拒绝操作。

TCP 转发能力与配置校验参考 [HAProxy TCP 文档](https://www.haproxy.com/documentation/haproxy-configuration-tutorials/protocol-support/tcp/) 和 [HAProxy 2.6 配置手册](https://docs.haproxy.org/2.6/configuration.html)。

## 常见问题

### SKYBYTE Manager 支持哪些 VPS 系统？

支持使用 systemd 的 Ubuntu/Debian VPS，官方资产映射支持 amd64、arm64、armv7 和 386，运行管理功能需要 root 权限。自动化测试配置覆盖 Ubuntu 24.04 和 Debian 11、12、13 的 amd64 环境；其他系统版本与架构需自行验证。

### Hysteria2 必须购买域名和证书吗？

不必。HY2 可以自动生成带公网 IP 的自签名证书，但客户端需要建立可信验证，不能默认跳过 TLS 验证。域名部署可使用已有证书或申请 ACME 证书；个人 HTTPS 在线订阅需要域名和可信证书。

### 小火箭、v2rayN 和 Clash Verge 如何导入节点？

菜单 **b → 2** 导出客户端文件，**b → 4** 显示小火箭节点二维码。文件在 VPS 的 `/etc/singbox-v2/`，可通过 SSH/SFTP 获取。Clash Verge Rev/Mihomo 使用完整 YAML，OpenClash 可合并 Mihomo 配置片段；请核实所用内核的协议支持。个人在线订阅通过 **b → 6** 单独启用。

### WARP 出站一定能解锁流媒体和 AI 服务吗？

不能保证。可选择全局直连、全局 WARP 或仅指定流媒体与 AI 域名走 WARP；实际可用性取决于出口 IP、平台策略及账户。流媒体检测结果仅表示检测时的 VPS 出口响应。
